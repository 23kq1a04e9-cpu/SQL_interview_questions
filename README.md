## Suggested study method

- Read one answer and explain it aloud in your own words.
- Practise the SQL query yourself.
- Use the memory cue for quick revision.
- Test your understanding by changing the example data or condition.

**Note:** These are curated practice questions, not a guaranteed ranking of questions asked by every company.
